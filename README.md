# 🚀 Сайт-открытка к Дню космонавтики

**Интерактивный веб-проект, посвященный Дню космонавтики (12 апреля).** 
Этот сайт сочетает в себе атмосферное поздравление и увлекательную мини-игру, позволяя пользователям не только получить праздничный настрой, но и проверить свою сообразительность в космических декорациях.

---

## 🌌 О проекте
Проект создан для создания праздничной атмосферы и популяризации темы космоса. Он выполнен в виде одностраничного приложения (SPA-подобный опыт на чистом JS), где пользователь сначала видит красивое анимированное поздравление, а затем может перейти к разгадыванию «Космических пятнашек».

---

## ✨ Функционал

### 1. 🎉 Поздравление пользователей
* **Анимированный лендинг**
* **Тематическое оформление:** Использование космической палитры, шрифтов в стиле футуризм/ретро-футуризм.

### 2. 🧩 Игра «Космические пятнашки»
* **Классическая механика:** Игра 15 (sliding puzzle) на сетке 4x4.
* **Космический дизайн** 
* **Алгоритм перемешивания:** Генерация случайной, но **гарантированно решаемой** комбинации при старте.
* **Счетчик ходов и таймер:** Отслеживание статистики игрока.
* **Проверка победы:** Автоматическое определение собранной картинки с выводом поздравительного модального окна.

---

## 🛠 Использованные технологии

Проект реализован без использования тяжелых фреймворков и библиотек, что демонстрирует глубокое понимание базовых веб-технологий:

| Технология | Применение в проекте |
| :--- | :--- |
| **HTML5** | Семантическая верстка, структура игры (сетка), доступность (a11y). |
| **CSS3** | Стилизация космического фона, Flexbox/Grid для сетки пятнашек, `@keyframes` для анимаций звезд и переходов, адаптивность (Media Queries). |
| **JavaScript (ES6+)** | Логика игры, обработка кликов, алгоритм проверки решаемости, работа с DOM, управление состоянием игры, таймеры. |

---

## 🎮 Как играть в «Космические пятнашки»
1. Нажмите кнопку **«Перемешать»** на экране поздравления.
2. Кликайте по плиткам, соседствующим с пустой ячейкой, чтобы перемещать их.
4. Ваша цель: собрать цельное изображение за минимальное количество ходов.
5. При успешном сборе вы увидите финальную анимацию и сможете начать заново!

## 🚀 Запуск проекта

Поскольку проект написан на чистом HTML/CSS/JS, для его запуска не требуется установка зависимостей (npm/yarn).

1. Клонируйте репозиторий или скачайте архив с файлами.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Наслаждайтесь космическим путешествием! 🌠
